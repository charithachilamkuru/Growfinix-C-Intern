
# 🏏 Sports Data Sorter (Custom Algorithms)

## Description

A C program that manages and sorts cricket player statistics using custom sorting algorithms. The project implements **Quick Sort** and **Merge Sort** from scratch and uses **function pointers** to switch between different sorting criteria.

## Tech Stack

* C
* Function Pointers
* Quick Sort
* Merge Sort

## Features

* Display player data
* Sort by Strike Rate
* Sort by Boundaries
* Sort by Player ID
* Menu-driven interface

## Concepts Used

* Structures
* Functions
* Arrays
* Function Pointers
* Sorting Algorithms
