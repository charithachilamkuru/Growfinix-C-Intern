# 🚀 Task 3: Fast String Parser for Server Logs (C)

## 📌 Description
This project implements a high-performance log parser in C using pointer arithmetic. It processes large web server logs to extract HTTP status codes and count error occurrences efficiently.

## ⚙️ Tech Stack
- C Programming
- Pointer Arithmetic
- File Handling

## 🚀 Features
- Reads large log files
- Extracts HTTP status codes
- Counts error codes (400–599)
- Optimized parsing using pointers
