# 🧳 Task 1: Tour Enquiry CLI Manager (C)

## 📌 Description

This project is a command-line application developed in C to manage tour enquiries. It allows users to perform basic CRUD (Create, Read, Update, Delete) operations and stores data persistently using a binary file.

---

## 🚀 Features

* ➕ Add a new enquiry
* 📖 View all enquiries
* 🔍 Search enquiry by ID
* ✏️ Update existing enquiry
* ❌ Delete enquiry

---

## 🛠️ Technologies Used

* C Programming Language
* Standard Libraries: `stdio.h`, `stdlib.h`, `string.h`
* File Handling (Binary File Storage)

---

## 📂 Project Structure

```
Task1_Tour_Enquiry_Manager/
 ├── main.c
 └── README.md
```

---

## 💾 Data Storage

* All records are stored in a binary file named `enquiry.dat`
* This file is automatically created when the program runs

---

## ▶️ How to Run

1. Open the project in Dev C++ (or any C compiler)
2. Compile the code (`main.c`)
3. Run the program
4. Use the menu options to perform operations

## 📋 Sample Workflow

1. Add a new enquiry
